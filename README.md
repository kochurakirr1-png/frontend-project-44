# Brain Games

Набор из 5 математических игр для терминала.

## Установка

```bash
git clone https://github.com/kochurakirr1-png/frontend-project-44.git
cd frontend-project-44
npm install
npm link
```

## Игры

**brain-even** — Определить, чётное ли число

**brain-calc** — Вычислить арифметическое выражение

**brain-gcd** — Найти наибольший общий делитель

**brain-progression** — Найти пропущенное число в прогрессии

**brain-prime** — Определить, простое ли число
